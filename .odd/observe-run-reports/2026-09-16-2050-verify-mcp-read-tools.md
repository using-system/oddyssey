## 6. Decisions the spec must settle

1. **Which deployment shape the read-tools bar rules on.** Unchanged from the baseline and still open: F9 is ~+15–20 ms per process start and nothing per request, a net loss for the one-shot driver this lineage measures and a net gain for the long-lived session server the package installs. 5. **F8's scope**: whether the launcher's ~600 ms (interpreter start, inspector client) is in scope for this lineage at all, or stays informational.
6. **What check 10 should assert.** The reset census depends on the pre-state (a running container, a stopped one, none): this run's reset ran against a down stack and answered 26 spans / 8795 ms against the check's 3–7 s band.
